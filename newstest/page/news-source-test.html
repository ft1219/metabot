How the pick will be made

These rules were set before any results came in, so the numbers can't be bent to fit a favourite.

  1. No verdict until at least 30 questions are scored.
  2. If Both beats a single source by more than luck explains (its whole range left of zero), keep Both.
  3. If a single source is not clearly worse than Both, pick the cheaper one: ChatGPT only, which is free.
  4. AskNews only can win only if it clearly beats ChatGPT only too, because it costs money once the wallet is empty.

How the test is fair

  • Every setup reads the news the bot actually had on the day it forecast, saved from its own logs. Searching again now would find the answers.
  • All four use the same AI model (GPT-6 Sol, the MiniBench model) and the bot's own instructions, so the news is the only difference.
  • Only questions that have already resolved are used. Nothing is posted to Metaculus.
  • Scores use Metaculus's own baseline scale: 0 is a know-nothing guess, higher is better.
